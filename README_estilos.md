# Estilos utilizados

## Estructura de una diapositiva

<!-- Título de sección -->
<section>
    <h2>Título sección</h2>
    <h3>Subtítulo</h3>
    <p>...</p>
    <!-- Cualquier elemento como fragmentos de código, vídeos, imágenes, notas del orador... -->
</section>

## Fragmento de código

<pre>
    <code class="hljs" data-trim data-line-numbers="1-2"> 
        // Código fuente
    </code>
</pre>

## Notas del orador

<!-- Notas orador (pulsar S) -->
<aside class="notes">
    Texto que sólo ve el orador
</aside>

## Resaltar al hacer clic
